أسئلة شائعة

تفاصيل تساعدك قبل التنزيل والاستخدام.

ما نظام التشغيل المطلوب؟

يستهدف KiT Tools نظام Windows 10 أو أحدث. قد تحتاج بعض مهام النظام إلى تشغيلها بموافقة المسؤول.

كيف أحصل على أحدث إصدار؟

زر التنزيل يفتح صفحة الإصدارات الرسمية للمشروع على GitHub، حيث تجد الملفات وملاحظات الإصدار.

هل يمكن استكمال التنزيل بعد إيقافه؟

يدعم مدير التنزيلات الاستكمال عندما يسمح خادم المصدر بذلك؛ وقد لا يتوفر هذا الخيار لكل رابط.

هل يحذف التنظيف ملفاتي تلقائيًا؟

تختار عناصر التنظيف بنفسك. العناصر التي قد تؤثر في بيانات المستخدم أو النظام غير محددة افتراضيًا.

هل الواجهة عربية؟

نعم، صُمم التطبيق بواجهة عربية واتجاه من اليمين إلى اليسار، مع إعدادات للغة والثيم.

KiT Tools for Windows

KiT Tools brings hardware monitoring, gaming tools, download management, system utilities, and network diagnostics into one Arabic-first Windows app. View CPU, GPU, memory, storage, network, and running processes; manage startup apps, installed software, drivers, printers, screenshots, and more.
