## نظرة عامة

بدل التنقل بين صفحات Windows وأدوات منفصلة، يضع KiT Tools مجموعة من مهام الاستخدام اليومي في واجهة واحدة. تبدأ من لوحة معلومات الجهاز، ثم تنتقل إلى القسم المناسب: التنزيلات، تثبيت البرامج أو إزالتها، بدء التشغيل، الأداء، الشبكة، التنظيف، لقطات الشاشة، الطابعات، التعريفات أو الإعدادات.

## الميزات

### لوحة المعلومات ومراقبة الجهاز

- متابعة استخدام وتردد وحرارة المعالج، واستخدام البطاقة الرسومية وحرارتها وذاكرة VRAM.
- عرض الذاكرة RAM والأقراص وسرعات الرفع والتنزيل عبر الشبكة.
- مراجعة العمليات الجارية واستهلاكها للمعالج والرسوميات والذاكرة والقرص والشبكة.
- الاطلاع على تفاصيل العتاد مثل المعالج والبطاقة الرسومية واللوحة الأم والذاكرة.

### الأداء والألعاب ونافذة Overlay

- متابعة الألعاب التي تختارها وتفعيل إعدادات وضع الألعاب حسب تفضيلاتك.
- رفع أولوية اللعبة النشطة مؤقتًا وإعادتها بعد انتهاء اللعبة.
- عرض مؤشرات الأداء فوق الشاشة، مثل CPU وGPU والذاكرة والحرارة وFPS والتخزين والشبكة.
- اختيار المؤشرات الظاهرة وضبط مظهر نافذة Overlay وحجمها.

### مدير التنزيلات

- إدارة تنزيلات الملفات والروابط من قائمة واحدة مع متابعة التقدم والسرعة والحجم والوقت التقديري.
- إيقاف التنزيلات واستئنافها عندما يسمح المصدر بذلك، وإدارة عدة عناصر في القائمة.
- ضبط حد السرعة وجدولة التنزيلات وتصفية القائمة حسب النوع أو الحالة.
- إضافة مصادر فيديو مدعومة؛ تختلف إمكانية التنزيل والاستئناف والجودة باختلاف المصدر.

### تثبيت البرامج وإزالتها

- استعراض كتالوج برامج قابل للبحث والتصفية حسب الفئة.
- تحديد عدة برامج للتثبيت وإدارة قائمة التطبيقات ومجلد الملفات التي تم تنزيلها.
- استعراض برامج سطح المكتب وتطبيقات Microsoft Store والبحث والترتيب حسب معلوماتها.
- إتاحة خيارات تنظيف بقايا البرنامج بعد إزالته عند اختيارها.

### إدارة بدء التشغيل والتعريفات

- عرض عناصر بدء التشغيل المسجلة في Registry أو مجلد Startup وتمكينها أو تعطيلها.
- مراجعة معلومات الناشر وتأثير بدء التشغيل وموقع الملف عند توفرها.
- إعداد مستقل لتشغيل KiT Tools عند بدء Windows.
- البحث عن تحديثات التعريفات عبر Windows Update واختيار المتاح منها، مع فتح Device Manager.

### الشبكة والاختصارات

- أدوات تشخيص مثل اختبار السرعة وPing واكتشاف أجهزة الشبكة وفحص المنافذ.
- مراجعة تفاصيل محوّلات الشبكة: IP وDNS والبوابة والـ Subnet وMAC.
- اختصارات لبعض إجراءات التشخيص مثل مسح DNS وتجديد عنوان IP وإعادة ضبط مكونات الشبكة.
- وصول سريع إلى أدوات وخيارات شائعة في Windows.

### التنظيف ولقطات الشاشة والطابعات

- اختيار عناصر التنظيف مثل الملفات المؤقتة وسلة المحذوفات وذاكرة المتصفح والسجلات وملفات Prefetch.
- التقاط الشاشة كاملة أو تحديد منطقة، مع مؤقت اختياري وخيارات الحفظ أو النسخ إلى الحافظة.
- اكتشاف الطابعات ومراجعة الحالة والتعريف والمنفذ وقائمة الانتظار.
- تعيين الطابعة الافتراضية وطباعة صفحة اختبار وإدارة قائمة الانتظار.

### الإعدادات والتخصيص

- إعدادات اللغة والثيم وتشغيل التطبيق مع Windows وفحص التحديثات.
- خيارات عامة مثل حد سرعة التنزيل وإدارة الاعتماديات المطلوبة.

## التنزيل والتثبيت

1. افتح [صفحة أحدث إصدار على GitHub Releases](https://github.com/DarkCalam/KIT-Tools/releases/latest).
2. نزّل ملف Windows المنشور ضمن **Assets** واتبع تعليمات الإصدار.
3. شغّل KiT Tools. قد تحتاج بعض مهام النظام إلى موافقة مسؤول Windows.

يمكنك أيضًا استخدام [الموقع الرسمي](https://kit-tools-app.github.io/) للتعرّف على البرنامج والوصول إلى أحدث إصدار وصفحة المشروع.

## متطلبات التشغيل

- Windows 10 أو أحدث.
- يتوفر التطبيق من خلال الإصدارات المنشورة في GitHub Releases.
- قد تتطلب بعض الوظائف صلاحيات مسؤول أو توفر مكوّنات Windows أو اعتماديات مرتبطة بها.

## البناء من المصدر

المشروع تطبيق WPF يستهدف **net10.0-windows**. لبناء نسخة Release تحتاج Windows و[.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0).

~~~powershell
dotnet restore KiT_Tools.csproj
dotnet build KiT_Tools.csproj -c Release
~~~

> **ملاحظة للمطورين:** يحتوي المشروع على خطوة Pre-Build قد تغلق عملية **KiT_Tools.exe** الموجودة. احفظ عملك وأغلق التطبيق قبل تنفيذ البناء.

## ملاحظات الاستخدام والصلاحيات

- بعض أدوات الأداء والشبكة تغيّر خيارات أو خدمات Windows، وقد تحتاج إلى صلاحيات مسؤول. راجع اختياراتك قبل تطبيقها.
- عناصر تنظيف الملفات أو بقايا الإزالة تُعرض كخيارات؛ تحقّق من العناصر المحددة قبل تأكيد العملية.
- استئناف التنزيل وجودة الوسائط يعتمدان على دعم المصدر.
- أدوات الشبكة مخصصة لتشخيص شبكات تملكها أو لديك إذن بفحصها.

# KiT Tools

### Everyday Windows tools, together in one app

Monitor your PC, manage downloads and apps, and access performance, network, and maintenance utilities from one desktop interface.

[Download the latest release](https://github.com/DarkCalam/KIT-Tools/releases/latest) · [KiT Tools website](https://kit-tools-app.github.io/) · [العربية](#arabic)

</div>

**KiT Tools** is a Windows desktop utility that combines hardware and process monitoring with download management, software and startup management, network diagnostics, printer tools, cleanup, screenshots, and more. Its interface supports Arabic right-to-left layouts while keeping technical values readable.

## Overview

Move between practical Windows tasks from one app: start with the system dashboard, then open downloads, app installation or removal, startup management, performance, network tools, cleanup, screenshots, printers, drivers, or settings.

## Features

### Dashboard and system monitoring

- View CPU load, clock, and temperature; GPU load, temperature, and VRAM; memory, disks, and network rates.
- Inspect running processes and their CPU, GPU, memory, disk, and network usage.
- Review hardware details such as the processor, graphics card, motherboard, and memory.

### Performance, gaming, and overlay

- Monitor games you configure and apply gaming-mode settings according to your choices.
- Temporarily raise the active game's priority and restore it after the game exits.
- Display CPU, GPU, memory, temperature, FPS, storage, and network metrics in an on-screen overlay.
- Choose visible metrics and adjust the overlay's appearance and size.

### Download manager

- Queue downloads and track progress, speed, size, and estimated time.
- Pause and resume downloads when the source supports it; manage multiple queue items.
- Set speed limits, schedule downloads, and filter by type or status.
- Add supported video sources; available quality and resume behavior vary by source.

### Install and uninstall apps

- Browse a searchable, filterable software catalog.
- Select multiple apps for installation and manage the app catalog and downloaded files.
- Browse desktop and Microsoft Store apps, with search and sorting options.
- Choose whether to clean up leftover files after uninstalling an app.

### Startup and drivers

- View startup entries from the Registry and Startup folder, then enable or disable them.
- Review publisher, startup impact, and file location when available.
- Configure KiT Tools to launch with Windows separately.
- Check for driver updates through Windows Update, choose available updates, and open Device Manager.

### Network and shortcuts

- Run diagnostics such as speed tests, ping, device discovery, and port checks.
- Review adapter details including IP, DNS, gateway, subnet, and MAC address.
- Access actions such as DNS flush, IP renewal, and network component reset.
- Open shortcuts to common Windows utilities and settings.

### Cleaner, screenshots, and printers

- Select cleanup categories such as temporary files, Recycle Bin, browser cache, logs, and Prefetch files.
- Capture the full screen or a selected region, with an optional delay and save or clipboard options.
- Discover printers and inspect status, driver, port, and print queue.
- Set a default printer, print a test page, and manage the queue.

### Settings and customization

- Configure language, theme, launch-at-startup behavior, and update checks.
- Adjust general options such as download speed limits and dependency management.

## Download and install

1. Open the [latest GitHub Release](https://github.com/DarkCalam/KIT-Tools/releases/latest).
2. Download the published Windows file from **Assets** and follow the release instructions.
3. Launch KiT Tools. Some system tasks may request Windows administrator approval.

Visit the [official website](https://kit-tools-app.github.io/) for an overview, the latest release, and the project page.

## Requirements

- Windows 10 or later.
- Published builds are available from GitHub Releases.
- Some features may require administrator privileges or Windows components and related dependencies.

## Build from source

KiT Tools is a WPF app targeting **net10.0-windows**. Building a Release configuration requires Windows and the [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0).

~~~powershell
dotnet restore KiT_Tools.csproj
dotnet build KiT_Tools.csproj -c Release
~~~

> **Developer note:** The project has a Pre-Build step that may close a running **KiT_Tools.exe** process. Save your work and close the app before building.

## Usage and permissions

- Some performance and network tools change Windows options or services and may need administrator privileges. Review your choices before applying them.
- Cleanup and uninstall-residue options can remove files or data. Check selected items before confirming an operation.
- Download resume and media quality depend on source support.
- Network utilities are intended for networks you own or are authorized to diagnose.
